# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Material Launcher, please do not open a public issue.

Instead, please report it via GitHub Private Vulnerability Reporting or open a security advisory on the repository.
You will receive a response within 48 hours.
